# Local Model Operations

本地模型的使用方式、执行规范、能力边界探索和实际经验的独立维护仓库。

本仓库从 [ck3_eternal_recurrence](https://github.com/XenoAmess/ck3_eternal_recurrence) 的本地模型运营资料抽取；项目中的业务代码和游戏运行账本继续由原项目维护。

当前共享服务为 `http://192.168.1.11:8080/v1`，模型为 `qwen38-coder`。这是指定局域网内的服务地址；各机器配置自己的调用者身份、目录和证据位置。

## 协作方式

仅使用 `main` 主线分支。按文件分配并行工作，每完成一个可审阅单元就及时提交、推送；Git 写入串行进行。详细规则见 [AGENTS.md](AGENTS.md)。

源码候选、HTTP 完成、软件验证、正式采用和真实业务结果分别记录。能力结论必须标明输入、版本、纠正成本和验证范围。
