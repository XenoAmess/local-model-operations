# 视频推理框架调研、实测与正式选型

2026-11-17。适用机器为单张 RTX 6000D（85,651 MiB，SM120），正式服务为 BF16 FastH3 Omni 与全本地 Open-H3-Regenerate-2K-IC 的 2K／4K 重生成。本文汇总本轮全部调研入口，区分源码调查、准入检查、内核测试、完整成片和正式采用。

## 用户确认的正式方案

用户已明确决定：

1. Omni 正式服务继续使用 **FastVideo**，模型名 `fasth3-omni-bf16`，入口 `http://192.168.1.11:8001/v1`。
2. 2K／4K 保留**当前已优化的 IC 后端**，模型名 `open-h3-2k`，入口 `http://192.168.1.11:8002/v1`，保持 `H3_IC_EXACT_IO=1`。
3. 全部调研和实测结果保存于本仓库 docs，部署代码、候选补丁与脱敏证据归入普通子目录 `deployments/video-generation/`。

这次确认不启动新基准，不安装或切换候选后端。此前追加的预热后量产对照已经取消；完整 H3 教师性能实验继续暂停。保留共享持久队列、按模型分组和等待公平性；完全本地、禁止云端、无开机自启，推理主内存 80 GiB、聚合 88 GiB。

本次只读核对中，8001 `/v1/models` 返回 BF16、8 步、36 层解码器及共享 GPU 队列；8002 返回 2K／4K 尺寸及单窗口 4K 策略。调度器、两个正式 HTTP unit 和网页均 active，均 disabled 开机自启。这是接口与 unit 状态检查，没有新增生成任务，也不代替实际成片验收。

## 已完成结果与采用状态

| 项目 | 已完成的证据 | 结论／采用状态 |
| --- | --- | --- |
| 当前优化版 IC | 真实单层位级核对；完整 2K 成片 | **正式保留**；没有降低精度、步数或合并 IC LoRA |
| Accelerate CPU offload | 完整 2K 1506.335 秒；latent 与全部 RGB 像素相同 | 当前优化版 1498.407 秒；未观察到提速，0.529% 差值不作统计显著判断 |
| Diffusers group offload，无 stream | 完整 2K 1562.786 秒；latent 与全部 RGB 像素相同 | 此次慢约 4.30%，不替换 |
| Diffusers stream／低 CPU 内存接入 | 4096-token 检查 | 未通过位级一致性；没有进入大尺寸或完整成片，不概括为上游普遍缺陷 |
| SGLang 本地适配 | 两次独立启动后的完整 Omni 请求 667.679／661.582 秒；重复输入 613.511 秒 | 有提速迹象；输出等价及公平预热后量产排名未建立，不上线 |
| UniServe 本地适配 | 完整 Omni 请求 643.547 秒；CPU／GPU 混合流送准入已完成 | 不用冷启动判定淘汰；36L decoder 投影 FP16 存储与正式配置有差异，不上线 |
| Niko1221/Strata | H3 权重导入计划和启动准入实际执行 | 缺少该 H3 架构路径；无视频生成成绩 |
| ro99/strata | CUDA 二进制实际构建；H3 启动准入执行 | H3 model-type 不支持；无视频生成成绩 |
| 4K 并发 | 实际序列长度的主注意力：串行／双 stream／batch2 | 两份约 47.69 秒，吞吐差小于 0.02%；没有跑两条完整 4K，不采用完整并发 |
| 其它整体实现 | 官方源码、模型页、配方调查 | 只作为调查候选，未冒充本机完整视频测评 |

Omni 数据来自同一素材、提示和种子的请求，但环境与放置策略不同；这些完整成片耗时不能视为公平预热后量产排名。条件缓存是重复素材场景的真实收益，应与缓存关闭及不同素材场景分开报告。

## 尚未知与已纠正事项

- 公平预热后量产比较：原计划每个框架先完整预热一次，再测两条连续请求，单列条件缓存与启动；在完成前取消，没有该成绩。
- 全片一致性：IC 三条完整 2K 控制器路径已做 latent 和全部 RGB 对照；完整 4K 的控制器替换比较、优化前后完整 4K 对照尚未做。
- 长片：15 秒重叠窗口的软件支持和时间轴测试不等于真正 15 秒模型成片验收；15 秒 4K 与双完整 4K 并发尚未验收。Omni 最大原生尺寸本机已完成的是约 5 秒，不能承诺该尺寸 15 秒一定满足容量。
- PDD：FastVideo 自身已经融合输出头；“只有 SGLang 新增融合”这一说法不成立。
- 参考缩放：通用 H3 默认值不能代替 Omni 的继承覆盖；已确认 SGLang Omni 默认是 `diffusers`，显式设置后与原结果 MP4 SHA 相同。
- 质量：SGLang 景别不同说明输出有差异，不证明质量更差；也没有独立实验将差异归因于 PDD 或注意力。
- UniServe：撤回根据启动加首条总时间判断“不值得继续”的结论。服务冷启动不作为持续量产排名依据；阶段间必要的加载／搬运仍属于每条请求的实际成本。

完整数据、固定提交、补丁、环境差异和复现入口见实测报告；这些范围限制也适用于该表中的所有数字。
