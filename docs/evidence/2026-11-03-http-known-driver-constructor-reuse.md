真实任务是减少 `Known` 构造函数内对完整不可变 Driver 的重复 canonical 编码。owner 已完成检索和影响分析，并明确给出算法与两处 literal 修改位置。首次完整编码仍执行，原 history 正数检查仍先于编码；stamp、episode、Game、coverage、action row、observation version 与 transport Game 检查保留原顺序。只有 observation 引用同一不可变 Driver 时复用首次编码结果；不同 Driver 仍编码并逐字节比较。编码结果只活在构造调用内，不新增字段、公开 API、类型、权限缓存或文件/Native 调用。
