# 历史原文档案

本目录三份 Markdown 是原公开项目已发表版本的精确字节快照，用来保留真实探索过程，不作为新 worker 的操作入口。

来源提交、SHA-256、迁移方式及当前规范的适用边界见 [来源与迁移记录](../source-origins.md)。正文未加迁移横幅，也未修复原相对链接，以便保持字节相等；需要追溯旧链接时，在原项目的固定提交中查阅。

旧机器路径、历史地址、业务权限、旧配置和早期产品兼容性分析仅说明当时状态。接手任务应先读本仓库根目录的 [AGENTS.md](../../AGENTS.md) 和 [README.md](../../README.md)，再使用现行配置与使用文档。
